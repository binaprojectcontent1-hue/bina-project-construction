## 🔧 Pattern for Replacing Each File

**Step 1:** Remove Lucide import line:
```typescript
// REMOVE THIS LINE:
import { Icon1, Icon2 } from 'lucide-react';
```

**Step 2:** Add Icons object after imports:
```typescript
// ADD AFTER IMPORTS:
const Icons = {
  IconName: ({ className }: { className?: string }) => <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2" strokeLinecap="round" strokeLinejoin="round" className={className}>
    <!-- SVG path here -->
  </svg>,
};
```

**Step 3:** Replace usage from `<IconName className="..." />` to `<Icons.IconName className="..." />`

## ⚡ Quick Batch Script Alternative

If you want to automate completely, use this PowerShell command:

```powershell
# This script adds solar icon definitions to all dashboard TSX files
$dashDir = 'D:\binaproject\apps\dashboard\src'
Get-ChildItem -Path $dashDir -Recurse -Include *.tsx,*.ts | ForEach-Object {
  if ($_ | Select-String "lucide-react") {
    # Read file content
    $content = Get-Content $_.FullName -Raw
    
    # Remove lucide import line
    $content = $content -replace "^import.*from\s+['""]lucide-react['""];?\r?\n", ""
    
    # Write back
    Set-Content $_.FullName $content -Encoding UTF8
    Write-Host "Processed: $($_.Name)" -ForegroundColor Green
  }
}
```

Then manually update icon usages in JSX.
